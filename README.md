============================================
    BOOKSTOSCRAPE SCRAPER
============================================

A Python script that scrapes **all 1000 books** from books.toscrape.com and saves them in CSV format.

-------------------------------------------------
FEATURES
-------------------------------------------------
- Saari 50 pages scrape karta hai
- CSV file mein save karta hai
- Console par progress dikhata hai

-------------------------------------------------
HOW TO RUN
-------------------------------------------------
1. Libraries install karo:
   pip install requests beautifulsoup4

2. Script run karo:
   python main.py

3. Output all_books.csv file mein milega.

-------------------------------------------------
FILES
-------------------------------------------------
main.py      - Scraping script
all_books.csv - Scraped data (auto-generated)
